# Regional refinement checkpoint, 3 October 2026

0.4.0 adds a cancellable NumPy CPU worker for anchored surface graph diffusion, exact rigid policies, digit exclusions, selected scope, seam reconciliation and artist protection. All application creates independent object/data copies. The AI proposal also respects protected rows and Blender vertex-group weight locks. Region masks and policy metadata persist on project meshes and copies; source changes invalidate an in-flight result.

The graph contains mesh edges and conservatively verified matching boundary edges. Seam verification checks opposite winding, face-normal compatibility and digit identity; it adds no nearest-neighbor edges between disconnected surfaces. This heuristic is not a semantic proof. Ambiguous seams, overlapping layers and conflicting artist constraints need review or disabled linking. The NumPy input budget is 512 MiB; solving can need several times the input allocation. Source extraction/graph preparation and final copy creation still run on Blender's main thread. The longer diffusion phase is isolated and Escape-cancellable.

AUTO keeps body weights, labels digit scope from accepted weights and resolves confident nearby finger identity using the accepted rest-bone segments. The first weight-only routing trial passed structural tests and reduced mean reference difference, but visibly sharpened a bad index crease. Joint evidence resolved 133 mislabeled/ambiguous vertices in the Shane test and eliminated that visible failure. This illustrates why aggregate metrics alone are insufficient. Imported weights are a withheld comparison, not an infallible quality label.

The final private Shane trial preserves unlabeled body weights exactly. Index-rotation mean reference difference falls from 0.481 mm to 0.028 mm; maximum falls from 49.74 mm to 14.96 mm. The index-second-joint grip test falls from 0.269 to 0.023 mm mean and 35.71 to 5.90 mm maximum. Remaining errors and one-avatar coverage prevent a broad quality claim. Reference/AI/refined posed renders were inspected. No private geometry, renders or weights are distributed.

Controlled acceptance covers close disconnected digits, verified UV-style seams with identical result weights, opposing coincident contacts without links, protected rows and locked columns preserved exactly, rigid rings and mechanical plates preserving pairwise distances after rotation, conflicting rigid/locked constraints failing before allocation, stale artist edits and corrupt worker constraints rejected, duplicate application, public undoable apply and owned-process cancellation. A cached validated neural result tests protection across a new AI job without rerunning model inference; transport input hashes match the previously measured real inference.

Fresh Unity 6000.3.21f1 imports the final regional FBX as a valid Humanoid, retaining two skinned meshes and three morphs. Vertices and bind matrices remain unchanged; independently evaluated Blender export-policy LBS agrees with Unity Generic within 1.70 micrometers. The monitored live Blender scene still contains only its original 67-bone armature, unchanged and unsaved, after extension reload. This milestone did not change the user's Unity project or its dirty scenes.

Volume heat/geodesic candidates and unbound geometric baselines remain next work. This implementation is an anchored graph heat refinement; it does not claim equivalence to a full cotangent harmonic/biharmonic solver or to the proprietary voxel diffusion addon. Rigidity is an accepted explicit movement policy, not guessed solely from distance or object naming. Joint-placement, optional twists and motion finishing also remain outstanding.
