# Creature rigs · Rigmodo 0.14.0

Choose **Rig → Creature → Generate Rig** with one character's meshes selected. UniRig predicts a variable hierarchy, without imposing Mixamo's humanoid bones. A new editable review rig and geometry copy are created; source geometry, rig, UVs and materials remain intact. **Edit Joints** uses Blender's native editor. Every deform bone is named `Creature_NNN`; `Root` is structural and unweighted. UniRig's predicted terminal directions are retained; only missing/zero-length display tails receive a short fallback.

**Skin Avatar** runs the existing local SkinTokens provider on these accepted custom joints. Successful skinning keeps the selected character's object names/identities. Surface/volume correction, rigid-region rules and weight painting remain available under Advanced skinning. Creature mode also routes imported custom rigs to this direct binding path. Human finger heuristics and humanoid pose-based deformation tests are not offered for creatures. The complete automatic rig/skin/motion workflow remains humanoid-only.

Creature output uses Unity **Generic**. Native Blender posing/keyframes work; Kimodo generation, SAM image posing and full-body Auto Pose remain humanoid-specific. UniMate is a possible separate creature-motion integration; it is not part of this release.

## Setup and local execution

In **Extension Settings → Setup → Creature Rigging**, install the optional provider. It reuses the configured MIA Python runtime's Torch 2.7 CUDA installation, with its own small dependency directory. It does not change that runtime or load PyTorch into Blender. The model architecture/tokenizer are pinned to ComfyUI-UniRig revision `69ee59dc459d2da7cb0291930c1f944886c31d7c`; the external provider retains original GPL source/license. Standalone inference replaces ComfyUI operations with Torch modules/SDPA and omits the unused PointTransformer skin architecture. No ComfyUI process, spconv, flash-attention build or external bpy package is needed.

The skeleton checkpoint is pinned to `apozz/UniRig-safetensors` revision `d0ba4ef9784eee71dd88b47d207f0c2c8f9dd623`, SHA-256 `013bc852dec0ab9d5a89ce4be68d0993046f4a61f90ab1e94bdd944cb3ed6003`. A chosen existing checkpoint is verified and referenced in place. Otherwise setup looks for common local UniRig locations, then downloads one copy into the provider cache. On this machine it reuses `R:/ComfyData/models/unirig/skeleton.safetensors`.

Inference is offline after setup. It validates the checkpoint, installed source hashes and prepared geometry. The model receives **Blender Z-up** coordinates, converted from the shared glTF Y-up job transport; results are converted back before Blender import. The released mixed 65,536-point / 8,192-vertex maximum sampling configuration and 15-beam generation settings are used. Joint lists must be finite, acyclic, single-rooted and within the input normalization cube, with 2–256 deform joints. Modified geometry/rigs and changed requests/results reject application before allocating scene objects. Jobs use the existing processing overlay, scoped cancellation and undo-owning apply operator.

## Verification · 13 November 2026

The official public UniRig giraffe fixture passes fresh neural skeleton generation, custom-joint Blender construction, real native SkinTokens binding and a Unity Generic FBX bundle. It yields 37 joints plus Root, in 12.75 seconds including model startup, with 4.88 GiB peak Torch allocation on RTX 4090. Re-importing the exported FBX preserves all 38 bone names, with maximum joint world-position error `8.83e-6` m. Unity Editor import has not been repeated.

The user's live Scorpion (1,632 vertices, existing 44-bone Tripo rig) was tested directly. The corrected adapter generates 51 joints plus Root, in 17.39 seconds with 4.95 GiB peak Torch allocation. AI skinning completes without creating another character or replacing the accepted armature data. Original geometry, joints, pose and paint stay intact; the original `.blend` on disk was not overwritten. Private before/review copies were saved outside the repository. One earlier trial remains hidden because the conservative cleanup guard did not establish that it was safe to remove.

**This is a working model integration, not a guarantee of a production-ready creature rig. The Scorpion's raised tail still requires manual joint correction.** More joints do not imply better placement, and complex insects, tightly folded limbs, accessories and rigid shells remain difficult. Review articulation before animation/export; re-skin after editing rest joints. The existing imported Tripo rig remains available for comparison or direct skinning.

Fresh humanoid UI/landmark regression passes with actual MIA inference after the older temporary fixture had been removed. Stale source/cyclic result rejection, source preservation, creature UI routing and real GUI cancellation are checked separately. The dated acceptance record distinguishes native inference, GUI checks and the untested Unity Editor import. Checkpoints, source meshes, private `.blend` files and dependency packages are excluded from the extension ZIP.
